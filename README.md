# ChatBox
• Built a real-time chat application using Java (Servlets/JSP) with Maven for build 
automation. 
• Implemented user authentication and session management to ensure 
secure messaging. 
• Integrated WebSocket-based communication for instant message 
delivery between users. 
• Designed a responsive front-end with HTML, CSS, JavaScript, and 
Bootstrap.
• Used MySQL for storing user profiles and chat history. • Followed MVC 
architecture and best practices for modular, maintainable code.
